# Lost & Found Campus

## Project Description

Lost & Found Campus is a web application designed to help students report, search, and manage lost and found items within a campus.

The platform provides a centralized place where users can post details about lost or found belongings and browse existing listings to help reconnect items with their owners.

## Key Features

- Report lost items
- Report found items
- View available lost and found items
- Search for items
- Filter items based on status
- View detailed item information
- View previously posted items
- Responsive and user-friendly interface

## Project Structure

The project consists of two main parts:

### Frontend

Built using React.js, Vite, JavaScript, and Tailwind CSS.

It includes pages and components for:

- Home
- Post Item
- Item Details
- My Posts
- Search
- Filters
- Navigation
- Item Cards
- Status Badges

### Backend

Built using Node.js and Express.js.

It provides REST APIs for managing lost and found item data and connects to MongoDB using Mongoose.

## Database

MongoDB is used to store information about lost and found items.

## Security

Environment variables are used for database configuration and sensitive information.

The `.env` file is excluded from the Git repository using `.gitignore` to prevent private configuration from being publicly exposed.
